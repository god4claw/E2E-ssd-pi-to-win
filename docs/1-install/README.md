# Часть 1. Установка

Установка идёт в два конца: сначала Pi (система, диск, пользователь, доступ), потом Windows (ключ, rclone, диск). Заканчивается приёмкой — списком проверок, после которых схему можно считать собранной.

| § | Тема | О чём |
|---|---|---|
| [§1](01-pi.md) | Система и диск | Разметка NVMe, ext4, монтирование по UUID, пользователь-хранитель |
| [§2](02-ssh.md) | Доступ только по ключу | Отдельная пара, `authorized_keys` вне досягаемости, `chroot` + `internal-sftp` |
| [§3](03-windows.md) | Windows: rclone и диск | WinFsp, отпечаток хоста, два раздела конфигурации, команда монтирования |
| [§4](04-autostart.md) | Автозапуск | Задание планировщика, которое не умирает на третьи сутки и ждёт Pi |
| [§5](05-acceptance.md) | Приёмка | Одиннадцать проверок, включая восстановление и видимость диска |

> [!IMPORTANT]
> Порядок важен: правило SSH из §2 требует, чтобы каталог уже существовал и принадлежал root (§1), а ключ из §3 должен быть на месте до §2. Поэтому ключ создаётся первым, ещё до входа на Pi.
